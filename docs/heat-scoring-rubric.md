# 行业热度评分 Rubric（L1 Market Heat 的统一尺子）

> 目的：把"web 抓取信息 → 行业 heat"这一步从**主观拍分**变成**可复现规则**。
> 每个赛道（老+新）都按同一把尺子、同一组指标、同样的档位映射打分，才可比、可审、可刷新。
> 配套：`index.html` SCORE_MODEL（渲染）、`ARCHITECTURE §0.5`（5 层模型）、`ROADMAP A1`（终局 L2 派生）。
> 立于 2026-07-02。

## 0. heat 是什么（第一性）

heat **不是**"这行业火不火"的感觉。它只有一个用途：**预测未来 6–18 个月会不会冒出触发买阀的 Capex 事件**（北极星 + 决策3）。所以每个分都必须服务于"哪里会有阀门采购机会"，而不是新闻热度。

- **L1 = 纯市场温度，不判 ESG 能不能赢**（能不能赢是 L3 的 W，单列、不进 heat）。
- heat 是市场信号，赢面(W)是 ESG 视角——两者分离（决策 2026-06-29）。

## 1. 公式（已固化，勿改权重）

```
heat = C×0.40 + D×0.27 + Pol×0.20 + P×0.13     (C/D/Pol/P 各 0–100)
```
- **C（Capex，最重）领权**——它最直接是买阀触发器。
- **P（Price）降权**——产品价格对卖阀几乎无关，仅作景气参照。

## 2. 四个子分：指标 + 评分档表

打分**必须**先落到一个量化指标，再按档表映射。禁止跳过指标直接给分。

### C — Capex 固定资产投资/扩产强度（权重 .40）
> **口径（决策3/4）**：算的是**中资企业**的新建/扩产 capex——**含中企出海建厂**（中企出海算机会，经国内披露监测，如玲珑巴西/森松海外）。**剔除**：纯外资在华高壁垒项目（我们无渠道）、境外企业境外项目、境外环评。

| 指标（任一为主，取最强证据） | 档 |
|---|---|
| 连续大规模核准/在建（如核电8000亿）或行业FAI高增(+10%↑)+明确新建潮 | 85–95 |
| 行业FAI正增(+3~10%) 或 有具名中企大项目/龙头扩产/出海建厂潮 | 70–84 |
| FAI微增/持平(0~3%) 或 结构性大项目托底但整体扩产偏弱 | 55–69 |
| FAI负增(−8~0%) 或 成熟/去产能，仅零星技改 | 40–54 |
| FAI大幅负增(<−8%) 且 无中企capex信号 | <40 |

### D — 下游需求景气（权重 .27）
| 指标：开工率/订单/需求增速 | 档 |
|---|---|
| 需求爆发（两位数增长 / 开工率高位回升 / 订单满） | 80+ |
| 需求回暖、向好 | 65–79 |
| 需求分化 / 平稳 | 50–64 |
| 需求疲弱 / 下滑 | <50 |

### Pol — 政策支持强度（权重 .20）
| 指标：政策层级/力度 | 档 |
|---|---|
| 国家级专项规划 / 十五五重点 / 强国产替代政策 | 85+ |
| 明确产业政策 / 行业稳增长方案 | 70–84 |
| 一般引导 / 地方政策 / 技改目录 | 55–69 |
| 无明确政策抓手 | <55 |

### P — 产品价格趋势（权重 .13，最弱相关）
| 指标：产品价格走势 | 档 |
|---|---|
| 价格上行 | 65+ |
| 价格平稳 / 震荡 | 50–64 |
| 价格下行 / 原材料倒挂 | <50 |

## 3. Provenance（接地纪律，同 `matched_sentence`）

每个子分**必须**能溯源，记录：`指标值 + 来源机构 + asof`。裸数字不接受。
（当前落点：赛道对象的 `data[]`（数据点）+ `src[]`（来源）承载；下一步可加 `heatBasis` 逐子分出处。）

## 4. 精度纪律（决策10：不装假精度）

- 分只当**整十档语义**读（8x=高景气 / 6x=中上 / 5x=偏弱 / 4x=弱）。
- **两赛道 heat 差 <5 视为噪声**，不据此排序高下。
- 半年重评一次；指标过期（>2 季度无更新）标 `stale`，不当当前热度。

## 5. 刷新 & 终局（→ ROADMAP A1，判据4）

- **过渡（现在）**：web 抓取 + 本 rubric 人工/agent 评分，季度刷。web 抓取只是桥。
- **终局**：heat 从 **L2 引擎事件聚合**派生 = `f(该行业事件数 × 价值档 × 新鲜度)`——同一方法覆盖全部行业、自动刷新、天然是"中企 Capex"。届时 web 抓取退为广度兜底。

### L2 接管路线（blend）
```
heat_final = α × rubric_heat + (1−α) × l2_signal_normalized
```
- α=1（现在）：纯 rubric，L2 仅并行展示做印证/背离参照。
- α 随"该行业事件覆盖度"下降：某行业事件数/账户数达阈值 → 该行业 α 下调，L2 开始接管。
- α=0（终局）：源补齐（A0 政府源 + 微信/RSS 扩量）后，heat 纯 events 派生（ROADMAP A1/A2）。
